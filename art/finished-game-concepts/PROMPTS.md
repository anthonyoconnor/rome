# Little Rome — finished-game visual concepts

These three AI-generated gameplay mockups show an aspirational finished visual direction. They are not captures of the current browser prototype. Generated with the built-in image_gen tool on 2026-09-05.

- `01-early-settlement.png`: Early settlement, placing a new house.
- `02-service-planning.png`: Developed neighborhood, bathhouse coverage and housing improvements.
- `03-flourishing-town.png`: Mature town, courtyard housing and civic buildings.

The first image established the architecture, materials, lighting and interface. It was used as a visual reference for the other two. Original generated PNGs are preserved without image post-processing. Interface figures are illustrative.
